How I build

I'm a serverless full-stack engineer specializing in building fast, scalable web applications. Instead of standing up heavy, expensive backends that burn budget on idle cloud servers, I architect systems that run at the edge. By leveraging Cloudflare Workers, Firebase, and Cloudinary, I build applications with minimal server maintenance overhead, fast global load times, and automatic scaling built in from day one.

// selected work

Serverless · Edge · Payments

StoreLink

Architected, engineered, and launched a production multi-tenant e-commerce platform allowing social media vendors to deploy instant digital storefronts. Cloudflare Workers handle edge routing across tenants, Firebase Firestore and Auth manage data and identity, and Paystack handles payment processing end to end.

How it's built: Each vendor storefront is served through a Cloudflare Worker rather than a traditional per-tenant server, which means routing logic runs at the edge, close to the visitor, instead of round-tripping to a single origin server. That removes the idle-server cost of running infrastructure per vendor, and it scales automatically as vendor count grows, no provisioning, no server management, no capacity planning ahead of time.
